# Collective Force — הוראות הפעלה

הפרויקט כולל שתי אפליקציות HTML נפרדות: `collective_sum.html` לאיסוף מספרי הקהל, ו-`calculator_collective_force.html` למחשבון. `index.html` הוא דף כניסה אופציונלי. שתי האפליקציות משתמשות באותו npoint JSON bin.

## ה-bin המשותף שכבר הוכן

קישור לעריכת ה-bin ב-npoint: https://www.npoint.io/docs/bf376153dd8536f3966c  
כתובת ה-API לקריאה ולשליחה: https://api.npoint.io/bf376153dd8536f3966c

מזהה ה-bin כבר מוגדר בשני קובצי האפליקציה כ-`bf376153dd8536f3966c`. אם יוצרים bin חדש, מחליפים את הערך של `NPOINT_BIN_ID` בשני הקבצים בדיוק באותו מזהה.

ה-bin ציבורי. מי שמחזיק בכתובת שלו יכול לקרוא את תוכנו ולכתוב אליו; אין לשמור בו פרטים אישיים, סיסמאות או מידע רגיש. ה-bin הזה מיועד למספרים זמניים של מופע. npoint מציג את עדכון ה-API באמצעות POST כיכולת בבטא פרטית ואומר שהשירות מיועד לאחסון JSON קל, לא כ-backend מלא. הכתיבה ל-bin הציבורי שנוצר לפרויקט נבדקה והצליחה, אך השירות עשוי לשנות או להגביל אותה בעתיד.

## תהליך ההפעלה

1. פותחים את אפליקציית איסוף המספרים, מוסיפים מספר אחד או יותר ולוחצים **Submit · שליחה למחשבון**. הסכום מחושב במספר שלם מדויק גם למספרים ארוכים.
2. פותחים את המחשבון ולוחצים לחיצה ארוכה של כ-0.7 שניות על סמל השעון כדי לפתוח את ההגדרות הסודיות. מזינים את מספר החיזוי, מסמנים **Collective force**, ולוחצים **שמור והפעל**.
3. מקלידים את הביטוי שמוביל לתוצאה הנוכחית ולוחצים `=` במספר הלחיצה שהוגדר (ברירת המחדל: הלחיצה השנייה). המחשבון מציג את החיזוי פחות סכום המתנדבים. למשל: `1831848449 − 1067 = 1831847382`.
4. לוחצים `+` ומקלידים ספרות כלשהן, במספר לחיצות השווה לאורך הסכום. כל הקשה מוצגת כספרה הבאה של סכום המתנדבים במקום הספרה שהוקלדה. בדוגמה, אחרי ארבע לחיצות יוצג `1067`; לחיצה על `=` מחשבת בפועל `1831847382 + 1067 = 1831848449`. לדוגמה נוספת: חיזוי `1838485` פחות סכום `1673649` נותן ערך ביניים `164836`; אחרי `+`, שבע הקשות ספרה מוצגות כ-`1673649`, ולחיצה על `=` מגיעה ל-`1838485`.
5. בהופעה חדשה, לוחצים באפליקציית האיסוף על **איפוס סבב חדש**, ואז מוסיפים ושולחים את המספרים של הסבב הבא.

המחשבון בודק את ה-bin בערך כל ארבע שניות. בדרך כלל ייתכן עיכוב של עד כמה שניות בין Submit לבין הופעת הודעת הסנכרון. הסנכרון מתבצע ברקע ללא חיווי סכום או חיבור במחשבון. לאחר שליחת הסכום, יש להמתין כמה שניות לפני תחילת שלב ה-Collective Force.

## העלאה ל-GitHub Pages

מעלים לאותו repository את `index.html`, `collective_sum.html` ואת `calculator_collective_force.html`. אפשר להעלות גם את `README_HE.md` לתיעוד. ב-GitHub בוחרים **Settings → Pages**, מגדירים פרסום מהענף הראשי (`main`) מתיקיית השורש ושומרים. דף הכניסה יהיה בכתובת האתר של הפרויקט; ניתן גם לפתוח ישירות את `collective_sum.html` או את `calculator_collective_force.html`.

## מבנה הנתונים ב-npoint

ה-bin מחזיק את מצב הסבב האחרון במבנה דומה לזה:

```json
{
  "schemaVersion": 1,
  "status": "ready",
  "runId": "מזהה-סבב-ייחודי",
  "numbers": ["308", "555", "204"],
  "sum": "1067",
  "submittedAt": "2026-10-29T12:00:00.000Z"
}
```

המספרים והסכום נשמרים כמחרוזות כדי למנוע אובדן דיוק במספרים ארוכים. בעת איפוס הסבב, הסטטוס מתחלף ל-`idle`.


## התקנה מהירה דרך תג NFC

`collective_sum.html` מוגדרת כ-PWA: לאחר הפרסום ב-GitHub Pages היא יכולה להתווסף למסך הבית ולהיפתח בחלון standalone כמעט ללא ממשק דפדפן. ב-iPhone אי אפשר להתקין אוטומטית מהתג: פותחים את הקישור ב-Safari, לוחצים על **שיתוף → הוסף למסך הבית** ומאשרים. באנדרואיד פותחים את הקישור בדפדפן שתומך בהתקנת PWA ולוחצים על **התקנה** או על **הוסף למסך הבית**. כשהדפדפן מציג את כפתור ההתקנה בתוך האפליקציה, אפשר להשתמש בו.

אחרי שהאתר פורסם, כתובת הפרויקט תהיה בדרך כלל `https://<שם-המשתמש>.github.io/<שם-המאגר>/`. בתוכנת כתיבת תג NFC בוחרים רשומת **URL/URI** וכותבים לתג את כתובת האפליקציה המלאה, למשל `https://<שם-המשתמש>.github.io/<שם-המאגר>/collective_sum.html`. לאחר מכן מקרבים טלפון לתג, פותחים את הקישור ומתקינים לפי ההנחיות שעל המסך. התג פותח את הדף; מערכת ההפעלה עדיין דורשת אישור התקנה ידני.

ההתקנה מצריכה פרסום ב-HTTPS. שירות ה-worker שומר מקומית את מעטפת האפליקציה, אך שליחה וקליטה מול npoint מחייבות חיבור לאינטרנט.


החלפת הספרות פועלת בכל מכשיר שפותח את דף המחשבון הזה; היא אינה משתלטת על אפליקציית המחשבון המובנית של הטלפון. אחרי החלפת קבצים באתר, ה-service worker מתעדכן לגרסה חדשה ומפנה את המטמון הקודם.
